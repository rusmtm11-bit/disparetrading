# disparetrading.ru

Корпоративный сайт ООО «ДИСПЭР» (Dispare Trading). Хостинг — GitHub Pages, домен из файла `CNAME`.

## Как устроено

- `tools/content.py` — **все тексты сайта** на русском и английском, рядом друг с другом.
- `tools/build.py` — собирает из них готовые страницы: `*.html` (русский) и `en/*.html` (английский), `sitemap.xml`, `404.html`.
- `assets/css/site.css`, `assets/js/site.js` — оформление и анимации (дизайн-система «Открытая накладная»).
- `assets/fonts/` — шрифты Manrope, Inter, JetBrains Mono (лицензия SIL OFL), хранятся у нас: сайт не обращается к Google и другим внешним сервисам.

Чтобы поменять текст: правим `tools/content.py`, запускаем `python3 tools/build.py`, коммитим всё вместе. Готовые `.html` руками не правим — перезапишутся при следующей сборке.

## Адреса без .html

GitHub Pages сам открывает `/catalog` вместо `/catalog.html`. Все ссылки, canonical и sitemap — без `.html`; старые ссылки с `.html` продолжают работать.

## Язык

- Русская версия — в корне, английская — в `/en/`. Переключатель RU/EN в шапке; выбор запоминается в браузере посетителя.
- Без ручного выбора язык выбирается один раз за сессию по часовому поясу устройства и языку браузера: Россия и страны СНГ или русский язык браузера → русский, остальные → английский. Поисковые роботы не перенаправляются. Никакие данные никуда не отправляются.

## Персональные данные

Сайт не собирает данные: нет форм, счётчиков и внешних шрифтов. Поиск по артикулу просто открывает магазин shop.disparetrading.ru. Форма заявки и Яндекс Метрика появятся только после подачи уведомления в Роскомнадзор.
